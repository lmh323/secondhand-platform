# Recordings folder

Place the two final MP4 files here before building the ZIP:

- `system-demo.mp4` - implementation demo, no more than 4 minutes;
- `presentation.mp4` - presentation recording, no more than 5 minutes.

See `docs/submission/video-demo-script.md` and `docs/submission/presentation-script.md` for the exact recording plan. Do not create placeholder MP4 files; the final ZIP builder checks that real files are present.

# Submission Workspace

Stage 6 prepares the final COMP3211 archive. The project contains source code, PDF versions of the required documents, the official Honour Declaration template, recording scripts, and a ZIP builder.

The two MP4 recordings and the completed declaration require group-specific actions. The exact steps are in `video-demo-script.md`, `presentation-script.md`, and `honour-declaration-guide.md`.

Use `python tools/build_submission_zip.py --check-only` to see whether the final archive is ready. When all required files are present, run `python tools/build_submission_zip.py`.

# Honour Declaration Completion Guide

The official template is copied to the project root as `Project Honour Declaration - 2026.docx` and also kept in `docs/submission/` as a backup. Complete the official DOCX before building the final ZIP.

Fill in:

- every group member's full name and student ID;
- the agreed contribution percentage for each member;
- any required signatures or dates;
- the GenAI-use declaration truthfully.

The project used Codex/ChatGPT assistance for project scaffolding, documentation drafting, implementation support, test generation, and PDF preparation. The group should describe that assistance accurately in the official form and review all generated material before submission. Do not sign or submit a declaration that does not match the group's actual work.

The contribution percentages must sum to 100%. The completed DOCX must be placed at the root of the final ZIP archive with the official filename.
